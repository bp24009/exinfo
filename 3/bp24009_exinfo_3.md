## 課題 (3)

 `**ppi = -3` が実行されたときのメモリ参照の流れを、実際のアドレス例を用いて説明する。

関数 `func3` は引数として `int **ppi `を受け取る。このとき main 内の変数 `pi2` のアドレス `0x7ffd9dade080` が渡されているため、`ppi`には`pi2`のアドレスが格納されている。つまりこの時点で、ppiメモリの`0x7ffd9dade090`番地には「0x7ffd9dade080」という値が格納されている。

次に 

```c
ppi = (int *)malloc(sizeof(int));
```
が実行される。`malloc`によりヒープ領域に int 型分のメモリが確保され、その先頭アドレス`0x5e204cb676d0`を返す。ここで、*ppi への代入はppi が指している先を`0x7ffd9dade080`から`0x5e204cb676d0`へ書き換る。

この状態で **ppi = -3 が実行される。
まず、ppi のアドレス`0x7ffd9dade090`を参照し、そこに格納されている値`0x7ffd9dade080`を取得する。つぎに、先ほど取得した`0x7ffd9dade080`番地へとアクセスし、そこに格納されている値`0x5e204cb676d0`を取得する。最後に、特定された`0x5e204cb676d0`番地のメモリに対して、整数値-3をint型のデータとして書き込む。
